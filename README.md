# ☀️ Helios Solar & Power — Clean-Tech E-Commerce Platform

A production-ready, ultra-modern e-commerce platform engineered for solar panels, LiFePO4 battery storage systems, EV batteries, solar inverters, and turnkey rooftop energy solutions.

---

## ⚡ Tech Stack & Features

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Modern Electric Blue & Solar Amber palette)
- **Icons:** Lucide React
- **State Management:** React Context API with LocalStorage persistence for Cart, Wishlist, and Comparison
- **Interactive Clean-Tech Studio:** Dynamic 3-unit hardware switcher (550W TOPCon Bifacial, 5.12kWh LiFePO4 PowerVault, 3kW Turnkey Rooftop Kit) with live telemetry HUD simulation
- **Solar Sizing Engine:** Reactive multi-step sizing calculator matching rooftop capacity and government subsidy schemes
- **WhatsApp Direct Consultation:** Pre-filled dynamic BOM, quotation, and direct solar engineer assistance

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📱 Architecture & Optimization

- **Responsive Design:** Optimized across mobile (320px+), tablets, and high-resolution desktop screens.
- **Performance:** Next.js Image optimization, fast client-side navigation, and zero layout shift.
- **Compliance:** Designed for PM Surya Ghar Rooftop Solar, MNRE, and ALMM compliance standards.
